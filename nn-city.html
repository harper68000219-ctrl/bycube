Процедурный Нижний Новгород для UE5.8

пл. Свободы как играбельная сцена: улицы, дома, силуэт города — из открытых OSM-данных через Blender CityGenerator / iCity в Unreal Engine 5.8. Стабильные 60 FPS на средней видеокарте.

Рендер-сетка • пл. Свободы • LOD0/LOD1

Вид сверху на квартал: массы домов, улично-дорожная сетка, дворы. Полная сцена собирается в UE5.8 из FBX (Scale 100, Z-up) с UCX-коллизиями.

SM_Svoboda_01массы домов • LOD0–2
SM_Streetsдороги • landscape-коллизия
SM_Yardдворы • пропсы • свет

Стек и требования движка

Blender 5.2 + CityGenerator / iCity

OSM-импорт, процедурные фасады, чистка топологии, раскладка по кварталам.

FBX: Scale 100, Z-up

Единый масштаб под UE, пивот на нуле квартала, именование SM_Svoboda_*

UCX-коллизии

Боксы UCX_ на дом, улица — landscape-коллизия. Без per-poly физики.

LOD 0–2 + Nanite off

LOD0 до 20к tris, LOD2 — билборд. Culling distance 1500–4000 м.

Пайплайн: 3 шага

1. OSM → Blender

Выгрузка пл. Свободы, привязка координат, генерация масс домов и дорог.

2. Blender → FBX

Ретопо, UV2 под лайтмап, LOD, UCX, экспорт Scale 100 Z-up.

3. FBX → UE5.8

Датасеты уровней, стриминг, свет, тест 60 FPS, пак для игры.
