Кейс · UE 5.8 · OSM → Blender → UE

Процедурный Нижний Новгород для UE5.8

пл. Свободы как играбельная сцена: улицы, дома, силуэт города из открытых OSM-данных через Blender в Unreal Engine 5.8. Стабильные 60 FPS на средней видеокарте.

Бриф

Задача: собрать играбельный квартал Нижнего Новгорода для тестовой сцены в UE5.8. Данные только из открытых источников. Срок: 3 недели.

Scope

OSM-импорт пл. Свободы. Генерация масс домов и улиц. Ретопо, UV, PBR-материалы. Экспорт FBX Scale 100 Z-up. Коллизии UCX. LOD0-2. Интеграция в UE5.8.

Пайплайн: 3 шага

01

OSM → Blender

Выгрузка пл. Свободы, привязка координаты, генерация масс домов и дорог.

02

Blender → FBX

Ретопо, UV2 под лайтмап, LOD, UCX, экспорт Scale 100 Z-up.

03

FBX → UE5.8

Датасеты уровней, стриминг, свет, тест 60 FPS, пак для игры.

Результат

Играбельная сцена пл. Свободы в UE5.8. 60 FPS на средней видеокарте. Исходники: проект UE + пак FBX + текстуры.
