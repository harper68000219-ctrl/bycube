Процедурный НН для UE5.8

пл. Свободы как играбельная сцена: улицы, дома, силуэт города — из открытых OSM-данных через Blender CityGenerator в Unreal Engine 5.8. Стабильные 60 FPS на средней видеокарте. Лёгкая статичная витрина вместо тяжёлого canvas и 3D-вьювера.

Стек и требования движка

Blender 5.2 + CityGenerator

OSM-импорт, процедурные фасады, чистка топологии, раскладка по кварталам. Пивот на нуле квартала.

FBX: Scale 100, Z-up

Единый масштаб под UE, именование SM_Svoboda_*. UV2 под лайтмап, LOD0 до 20к tris.

UCX-коллизии

Боксы UCX_ на каждый дом, улица — landscape-коллизия. Без per-poly физики — дёшево и сердито.

LOD 0–2, Nanite off

LOD2 — билборд. Culling distance 1500–4000 м. Тест: 60 FPS на средней видеокарте.

Пайплайн: 3 шага

01

OSM → Blender

Выгрузка пл. Свободы, привязка координат, генерация масс домов и дорог.

02

Blender → FBX

Ретопо, UV2, LOD, UCX-обёртки, экспорт Scale 100 Z-up пакетами по кварталам.

03

FBX → UE5.8

Датасеты уровней, стриминг, свет, тест 60 FPS, пак для игры.
