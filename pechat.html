Бриф

Задача: напечатать партию 150 штук сувенирки для производства. Материал PETG, точность 0.1 мм, постобработка и покраска. Срок: 2 недели.

Scope

Подготовка модели к печати. Печать на Creality K1 SE. Постобработка: зачистка, грунт, покраска. Упаковка. Доставка по НН курьером, по России СДЭК.

Материалы

PETG основной. PLA для прототипов. ABS для прочных деталей. TPU для гибких элементов. Точность 0.1 мм, скорость до 600 мм/с.

Результат

150 штук за 2 недели. Допуски сошлись с первого раза. Доставка по НН курьером, по России СДЭК. Исходники: STL + 3MF + фото партии.
